## ⚠️ 已知安全事项：默认弱口令

`source/mkimg/` 的构建脚本在生成 rootfs 时会创建用户 **`eswin`**，密码默认为 **`eswin`**。

这是**弱口令风险**：任何接入同一网络的人都可以凭此登录设备。

**缓解措施：**

1. 构建前通过环境变量指定强口令：
   ```bash
   export USER_PASSWORD="<强口令>"
   bash setenv.sh
   ```
2. 若镜像已构建完成，首次登录后立即执行 `passwd` 修改；
3. 部署到生产或联网环境前，务必确认口令已更改，并考虑禁用密码登录、改用 SSH 密钥。

> 该口令以变量 `USER_PASSWORD` 形式配置，见 `source/mkimg/mkrootfs.sh`。

## 报告漏洞

**请勿通过公开 Issue 报告安全漏洞。** 请通过以下方式私下反馈：

- 安全邮箱：`<security@your-org.example>`（待填写）
- 或经由内部安全响应流程转交

请在报告中尽量包含：

- 漏洞类型与影响范围；
- 复现步骤 / PoC；
- 受影响版本与硬件配置；
- 建议的缓解或修复方案（如有）。

## 处理流程

1. 接收方在 **3 个工作日内**确认收到；
2. 评估严重性与影响，必要时成立临时应急小组；
3. 协商披露时间线（默认 **90 天**负责任披露，视风险可缩短）；
4. 修复合并后，在 Release Notes 中以 CVE / 内部编号致谢报告者（经同意）。

## 注意

- 本仓库默认不含密钥 / 凭证；若发现 `.env`、私钥等被误提交，请立即按上述渠道报告，我们将从 git 历史中清除；
- 第三方组件（如 OMV、内核）漏洞请同时关注其上游安全公告。
